## Purpose

React（CSR）製のPWAとして、チャット・カレンダー・設定の3画面を下部タブで切り替えられるアプリシェルを提供し、モバイル/デスクトップでホーム画面に追加（インストール）できるようにする。

## ADDED Requirements

### Requirement: 下部タブによる3画面ナビゲーション

アプリは画面下部のタブで「チャット」「カレンダー」「設定」の3画面を切り替えられなければならない（SHALL）。現在アクティブな画面がタブ上で識別できなければならない（SHALL）。

#### Scenario: タブで画面を切り替える

- **WHEN** ユーザーが下部タブのいずれかを選択する
- **THEN** アプリは対応する画面を表示し、選択中タブをアクティブ表示にする

#### Scenario: 初期表示

- **WHEN** アプリを起動する
- **THEN** アプリは既定画面（チャット）を表示する

### Requirement: チャット画面

チャット画面はメッセージの入力・送信と会話履歴の表示を行い、システムから提示された予定案に対して承認・却下の操作を提供しなければならない（SHALL）。

#### Scenario: メッセージを送信して応答を表示する

- **WHEN** ユーザーがメッセージを入力して送信する
- **THEN** チャット画面は送信メッセージとシステム応答（予定案を含む場合はその内容）を会話履歴に表示する

#### Scenario: 予定案を承認する

- **WHEN** チャット画面に予定案が提示され、ユーザーが承認操作を行う
- **THEN** アプリは承認を送信し、登録完了の結果を表示する

### Requirement: カレンダー画面

カレンダー画面は登録済みイベントを月表示または一覧で確認できなければならない（SHALL）。加えて、カレンダー画面から予定を手動で作成・編集・削除できなければならない（SHALL）。

#### Scenario: 当月のイベントを表示する

- **WHEN** ユーザーがカレンダー画面を開く
- **THEN** アプリは当月に該当するイベントを取得して表示する

#### Scenario: イベント詳細を確認する

- **WHEN** ユーザーがカレンダー上のイベントを選択する
- **THEN** アプリはそのイベントの詳細（名称・日時・場所・概要）を表示する

#### Scenario: 予定を手動で作成する

- **WHEN** ユーザーがカレンダー画面で新規作成を行い、名称・日時等を入力して保存する
- **THEN** アプリはイベントを作成し、カレンダー表示に反映する

#### Scenario: 予定を手動で編集・削除する

- **WHEN** ユーザーが既存イベントを選択して内容を編集して保存、または削除する
- **THEN** アプリは変更を反映し、削除した場合はカレンダー表示から除外する

### Requirement: 設定画面

設定画面はアプリ設定（少なくともタイムゾーン）の表示と変更を提供しなければならない（SHALL）。

#### Scenario: 設定を変更する

- **WHEN** ユーザーが設定画面でタイムゾーンを変更して保存する
- **THEN** アプリは設定を更新し、更新後の値を表示する

### Requirement: PWAとしてのインストール対応

アプリはPWAとして構成され、モバイル/デスクトップでホーム画面に追加（インストール）できなければならない（SHALL）。そのためにWebアプリマニフェストとService Workerを備えなければならない（SHALL）。

#### Scenario: ホーム画面に追加できる

- **WHEN** 対応ブラウザでアプリにアクセスする
- **THEN** アプリはインストール可能な状態（マニフェストとService Workerが有効）であり、ホーム画面への追加が行える

#### Scenario: アプリシェルのオフライン表示

- **WHEN** インストール済みのアプリを一度読み込んだ後に再訪する
- **THEN** Service Workerによりアプリシェル（静的アセット）がキャッシュから表示される
